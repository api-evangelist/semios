# Semios

> Semios (SemiosBio Technologies Inc., Vancouver, British Columbia) runs a large
> in-canopy IoT sensor network for permanent crops and layers pest, disease,
> frost, irrigation and plant-stress models on top of it. Growers and agronomists
> use it through the Semios Hub applications. Semios publishes no public
> developer portal and no machine-readable API contract; the Hub API is
> customer and partner authenticated.

Generated by the API Evangelist enrichment pipeline on 2026-08-26 from
apis.yml and live probes of Semios' own hosts. Not published by Semios.

## What Semios does

- Sensing: in-canopy climate monitoring, soil moisture, insect trap counts,
  plant-stress monitoring, reported on roughly ten-minute intervals.
- Crop protection: insect pest management including variable-rate aerosol
  mating disruption; disease management driven by degree-day and risk models.
- Water and frost: irrigation management and automation, frost management.
- Reporting: alerting and reporting tools, plus in-field agronomic services.
- Crops served: almonds, apples, cherries, citrus, grapes, pears, pistachios,
  stone fruit, walnuts.

## API surface

- Semios Hub API: https://hub-api.semios.com
  Live over HTTPS (TLS 1.3). Every anonymous path returns an application-level
  404 "Path not Found". No OpenAPI, Swagger, GraphQL, AsyncAPI, WSDL or
  Protobuf contract is published at the API host, the application host or the
  website. No /.well-known/ documents are served on any host.
  Human entry point: https://hub.semios.com/ (login required).
- There is no developer portal, no public API reference, no SDK on npm, PyPI,
  RubyGems, Maven Central, NuGet, crates.io or pkg.go.dev, no CLI, no hosted
  MCP server, and no A2A agent card.
- Integration is arranged directly with Semios. The published integration
  example is the WiseConn irrigation integration:
  https://semios.com/wiseconn-integration/
